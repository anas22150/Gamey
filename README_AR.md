# Party Legends — نسخة 3D الموسعة

لعبة Android أولية مبنية باستخدام Godot 4.4.1. جميع الألعاب في هذه النسخة ثلاثية الأبعاد:
1. Crystal Arena — اجمع البلورات.
2. Lava Escape — تجاوز منصات الحمم.
3. Turbo Race — سباق ضد الوقت.
4. Ball Bash — ادفع الكرة نحو المرمى.
5. Skyfall Survival — تفادى المكعبات الساقطة.
6. Treasure Hunt — اجمع الكنوز.

تدعم القائمة وضع لاعب واحد ضد خصم آلي ووضع لاعبين محليًا على الجهاز. في اللعب المحلي: اللاعب الأول بالأسهم/النصف الأيسر للمس، والثاني WASD/النصف الأيمن للمس.

## التشغيل والتصدير
- افتح `project.godot` في Godot 4.4.1.
- لتصدير APK ثبّت Android Export Templates وAndroid SDK وJDK 17، ثم Project > Export > Android.
- يوجد GitHub Actions workflow في `.github/workflows/build-android.yml`.

## حدود النسخة
هذه نسخة Prototype وليست إصدارًا تجاريًا نهائيًا. لم يتم تشغيلها داخل محرّك Godot أو التحقق من نجاح APK في بيئة بناء فعلية. قد تحتاج بعض أنظمة التحكم والفيزياء إلى ضبط بعد أول تجربة. لا يوجد اتصال أونلاين أو سيرفر؛ اللعب محلي فقط.
